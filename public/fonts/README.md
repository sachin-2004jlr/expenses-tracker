# Fonts

Put a **licensed** copy of Talina (Pandeka Studio) here as `talina.woff2` (or `talina.woff`,
`talina.otf`, `talina.ttf`). Section headings pick it up automatically; without it they use
Fredoka. The free Talina download is a personal-use demo, so buy a licence before using it on a
public site, and check the licence allows web embedding before committing the file to a public repo.
